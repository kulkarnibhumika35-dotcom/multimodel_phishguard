# PhishGuard

AI-powered phishing detection system that combines machine learning with a browser extension to identify and block phishing URLs in real time.

## Project Structure

- **backend/** — FastAPI REST API, database models, schemas, and business logic
- **extension/** — Browser extension for real-time phishing detection
- **ml/** — Machine learning pipeline: feature engineering, training, models, and evaluation
- **dashboard/** — Analytics and monitoring dashboard
- **datasets/** — Raw and processed datasets for training and evaluation
- **tests/** — Unit and integration tests
- **docs/** — Project documentation

## Getting Started

```bash
pip install -r requirements.txt
```
